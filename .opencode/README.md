# Local opencode Preferences

This folder contains project-local opencode settings for this repository.

Useful places to add preferences:

- `.opencode/opencode.json` for project-local config.
- `.opencode/agent/<name>.md` for local custom agents.
- `.opencode/command/<name>.md` for local slash commands.
- `.opencode/skills/<name>/SKILL.md` for local skills.

Restart opencode after editing these files. Config is loaded at startup.
